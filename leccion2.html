📗 Lección 2 — Ramas y Merge

¿Qué es una rama?

Una línea de trabajo paralela sin tocar main.

Comandos

ComandoQué hace
git branchVer ramas
git checkout -b mi-ramaCrear y cambiar
git checkout mainVolver a main
git merge mi-ramaUnir cambios

Flujo típico

git checkout -b mejorar-readme
# editas README.md
git add README.md
git commit -m "Mejorar README"
git checkout main
git merge mejorar-readme
