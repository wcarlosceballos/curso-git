🏅 ¿Listo para publicar tu primer sitio?

Con lo que aprendiste hoy puedes levantar un sitio estático gratis usando la rama gh-pages:

git switch -c gh-pages
cp -r contenido/* .
git add . && git commit -m "docs: publicar sitio"
git push -u origin gh-pages

Luego actívalo en Settings → Pages → Source: gh-pages. Tardará entre 1 y 10 minutos.
