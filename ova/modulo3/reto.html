🏆 Reto del Módulo 3 — GitHub

🎯 Misión

Demuestra que puedes publicar un proyecto limpio en GitHub y que entiendes cómo se trabaja con otras personas.

📝 Parte 1 — Preguntas

1. ¿Qué hace git fetch?

2. Te pide contraseña al hacer push por HTTPS. ¿Qué pones en el campo contraseña?

3. Quieres contribuir a un proyecto de otra persona. ¿Cuál es el flujo correcto?

4. ¿Para qué sirve el -u de git push -u origin main?

🧪 Parte 2 — Evidencia práctica

Tarea: publica un repositorio.

  1. Crea un repositorio nuevo en tu cuenta de GitHub
  2. Clónalo y añade un README.md con título y descripción
  3. Haz al menos 2 commits
  4. Pega abajo la salida de git remote -v




💡 Ver pistas

Si git push dice rejected, casi siempre es porque hiciste git pull después del último push. Ejecuta git pull y vuelve a subir.

El PAT se genera en Settings → Developer settings → Personal access tokens con permiso repo. Si se filtra, revócalo.

Con SSH evitas escribir credenciales: git@github.com:TU_USUARIO/REPO.git.
