🧠 Actividad 1 — Identifica el área

Antes de empezar a teclear, tienes que saber dónde estás parado. ¿En qué área de Git se encuentra cada acción?

1. Ejecutas git add app.js → ¿en qué área queda el archivo?

2. Ejecutas git commit -m "msg" → ¿en qué área queda?

🛡️ Actividad 3 — Antes del primer push

Este es el error que más damage causa y que todos cometen alguna vez. Marca los archivos que nunca deben subirse.
