📗 Lección 1 — Git Básico

¿Qué es Git?

Sistema de control de versiones: registra cada cambio de tus archivos.

Las 3 áreas

  1. Working directory — donde editas
  2. Staging area — preparas con git add
  3. Repository — commits con git commit

Comandos clave

ComandoQué hace
git initInicializa repo (una vez)
git statusVer estado
git add .Preparar todo
git commit -m "msg"Guardar
git log --onelineHistorial

Ejemplo

mkdir mi-proyecto && cd mi-proyecto
git init
echo "hola" > hola.txt
git add hola.txt
git commit -m "Primer commit"
git log --oneline
